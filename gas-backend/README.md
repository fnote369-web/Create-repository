# Future Letter 30days — Google Apps Script バックエンド

このフォルダのコードは、フロントエンド（`src/`）から呼び出される本番用バックエンドです。
Googleスプレッドシートをデータベースとして使い、Google Apps Script (GAS) をAPIサーバーとして動かします。
フロントエンドをGitHub Pages等で公開したままでも、**追加費用なしで運用開始できます**（Googleの無料枠の範囲内）。

## できること

- 利用者登録・ログイン（マジックリンク）・マイページ用API
- 30通の手紙の自動作成（テンプレート版／AI版、AI失敗時は自動でテンプレートにフォールバック）
- 毎朝の自動メール配信（時間主導トリガー、二重送信防止つき）
- 管理者API（統計・利用者一覧・テスト送信・手動送信・CSV出力・テストモード）

## セットアップ手順（初回のみ）

### 1. Apps Scriptプロジェクトを作成してコードを貼り付ける

1. [script.google.com](https://script.google.com/) にアクセスし、「新しいプロジェクト」を作成します。
2. プロジェクト名を「Future Letter 30days」などに変更します。
3. このフォルダにある `.gs` ファイルの内容を、同じファイル名でApps Scriptエディタにコピー＆ペーストします（`Code.gs`, `Utils.gs`, `SheetsService.gs`, `Users.gs`, `Letters.gs`, `Mail.gs`, `Admin.gs`, `Setup.gs`）。
   - エディタの「＋」から「スクリプト」を選び、拡張子なしのファイル名（例：`Code`）で作成してください。
4. 左メニューの歯車アイコン「プロジェクトの設定」を開き、`appsscript.json` の内容をこのフォルダの `appsscript.json` に合わせます（「マニフェスト ファイルを editor で表示する」にチェックを入れると編集できます）。

### 2. 初期セットアップ関数を実行する

1. エディタ上部の関数選択ドロップダウンで `setupAll` を選び、実行（▶）します。
2. 初回はGoogleアカウントへのアクセス許可を求められるので、承認してください。
3. 実行ログ（表示 > ログ）に、作成されたスプレッドシートのURLが表示されます。開いて確認してください。
4. 「プロジェクトの設定」→「スクリプト プロパティ」で、以下の値をご自身の内容に変更してください。

| プロパティ名 | 説明 | 例 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 管理者ログインのパスワード（**必ず変更してください**） | 十分に複雑な文字列 |
| `SITE_URL` | 公開後のフロントエンドURL（末尾に `/` を含む） | `https://your-username.github.io/your-repo/` |
| `SPREADSHEET_ID` | `setupAll`が自動設定します（通常は変更不要） | — |
| `AI_PROVIDER` | AIモードを使う場合。`anthropic` または `openai` | `anthropic` |
| `AI_MODEL` | 使用するモデル名 | `claude-sonnet-5` |
| `AI_API_KEY` | AIモードを使う場合のみ。**必ずスクリプトプロパティ経由で設定し、コードに直接書かないこと** | — |

`AI_API_KEY` を設定しない場合、AIモードを選んだ利用者にも自動的にテンプレート版の手紙が作成されます（フォールバック）。

### 3. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」を選択します。
2. 種類の選択で「ウェブアプリ」を選びます。
3. 「次のユーザーとして実行」を **自分（あなたのアカウント）** に設定します（Gmail送信のため）。
4. 「アクセスできるユーザー」を **全員** に設定します（匿名の利用者からのAPI呼び出しを受け付けるため）。
5. デプロイ後に表示される「ウェブアプリURL」（`https://script.google.com/macros/s/xxxx/exec`）をコピーします。

### 4. フロントエンドに接続する

リポジトリ直下に `.env.production`（または `.env`）を作成し、以下を設定してビルドし直します。

```
VITE_API_BASE_URL=https://script.google.com/macros/s/xxxxxxxx/exec
```

この環境変数が設定されている間、フロントエンドは自動的にローカルモードではなくこのGASバックエンドを使うようになります（`src/lib/api.js` 参照）。

### 5. コードを変更したときの再デプロイ

`.gs` ファイルを編集した場合、「デプロイ」→「デプロイを管理」→ 編集（鉛筆アイコン）→ 新しいバージョンを選んで「デプロイ」を押さないと、公開中のURLには反映されません。

## 注意点・既知の制約

- **Gmail送信数の上限**：個人のGoogleアカウントは1日あたり約100通、Google Workspaceアカウントはプランに応じて1,500通程度が上限です。利用者数が増える場合はご注意ください。
- **トリガーの実行間隔**：`setupTrigger` は15分おきに `sendDailyLetters_` を実行します。配信希望時刻ちょうどではなく、その時刻を過ぎた最初の実行タイミングで送信されます（最大15分程度のずれが生じます）。
- **CORS**：GASのウェブアプリはプリフライトが必要なリクエストにカスタムCORSヘッダーを返せないため、フロントエンドは `Content-Type: text/plain` のPOSTでプリフライトを回避しています（`src/lib/gasBackend.js`）。もしブラウザのコンソールにCORSエラーが出る場合は、デプロイ設定（アクセス権限が「全員」になっているか）と、デプロイが最新のコードを反映しているかを確認してください。
- **スプレッドシートを直接見られる人を絞る**：スプレッドシート自体の共有設定は既定では自分のみです。共有しないでください（個人情報が含まれます）。

# セッション予約アプリ（プロトタイプ）

カウンセリング／セッション系のサービス向け予約アプリです。お客様が日時・メニューを選んで予約し、オーナー（あなた）が対応可能日時・メニュー・予約状況を管理できます。

Cowork（claude.ai）で作成したプロトタイプを、このリポジトリに移植したものです。

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

画面上部の「お客様」「オーナー（あなた）」ボタンで立場を切り替えて体験できます（開発用。本番では非表示にできます）。

オーナーのデモ用ログイン：`you@example.com` ／ `owner1234`

## 構成

- `index.html` — 画面構造
- `style.css` — 見た目
- `app.js` — 予約ロジック・カレンダー計算・お客様/オーナー画面の制御

## メール送信（Google Apps Script連携）について

`app.js` 内の `MAIL_ENDPOINT` に、メール送信用のGoogle Apps Script（GAS）のURLを設定すると、予約確定・変更・キャンセル時にお客様とオーナーへ自動でメールが送られます。

**このリポジトリは公開（Public）のため、実際のURL・メールアドレスは意図的に空欄／ダミー値にしてあります。** 本番で使う際は、公開リポジトリにはコミットせず、手元の環境や非公開の設定でURL・メールアドレスを設定してください。

- `owner.email`（`app.js` 冒頭）— 通知を受け取る実際のメールアドレスに変更
- `MAIL_ENDPOINT`（`app.js` 冒頭付近）— あなたのGASのURLを設定
- `owner.password` — デモ用の簡易パスワードです。本番運用する場合はもっと安全な認証方式に置き換えることを推奨します

## 注意

これはプロトタイプです。決済はデモのため実際の請求は発生しません。本番運用する場合は、決済（Stripe等）・データの永続化（サーバー/データベース）・認証の強化が必要です。

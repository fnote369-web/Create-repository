# AIと歩む、わたしらしい６ヶ月。

心を整えながら、AIを人生や仕事のパートナーとして使いこなす６ヶ月間の伴走プログラムを紹介するランディングページです。

## 構成

- `index.html` — ページ構造（ヒーロー／プログラム概要／得られること／伴走の流れ／おすすめの方／クロージング）
- `style.css` — 配色・タイポグラフィ・レイアウト（ライト／ダークテーマ対応）
- `app.js` — ヒーローの星座風アニメーションとスクロール時のフェードイン演出

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

# インナーチャイルドカード

心の中にいる「小さな自分」に会いにいくための、めくって遊べるカードアプリです。

- 「カードを引く」でランダムに1枚のカードが選ばれます。
- カードをタップ（クリック）するとめくれて、裏面にイラストと言葉（メッセージと問いかけ）が展開します。
- 「カード一覧」タブでは、全12枚のカードをいつでも見返せます。

## 使い方

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 構成

- `index.html` — 画面構造
- `style.css` — 見た目とカードの3Dフリップアニメーション
- `cards.js` — 12枚のカードのデータ（テーマ・イラスト・メッセージ・問いかけ）
- `app.js` — カードを引く／めくる／一覧表示のロジック
